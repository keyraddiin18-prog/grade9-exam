1.1 Description of the Concept Set

Definition:
A set is a collection of well-defined objects or elements.

The phrase well-defined means that for any given object, we can clearly decide whether it belongs to the set or not.

Important Notation

  • Sets are usually represented by capital letters such as A, B, C, X, Y and Z.
  • Elements are represented by small letters such as a, b, c, x, y and z.
  • If a is an element of set A: a ∈ A
  • If b is not an element of A: b ∉ A
Example:
Let A be the set of vowels in the English alphabet.

i ∈ A
o ∈ A
b ∉ A

Well-defined and Not Well-defined Sets

Well-defined: The set of students in your class. All members can be clearly identified.
Not well-defined: The collection of handsome boys in your school. There is no exact rule to decide who is handsome.

1.1.1 Set Description

Sets can be described in four main ways:

i. Verbal Method (Statement Form)

The elements of the set are described using words or an English statement.

Example:
The set of all even natural numbers less than 10.

ii. Complete Listing Method (Roster Method)

All elements of the set are listed, separated by commas and enclosed in braces { }.

Example:

Even positive integers less than 7:

{2, 4, 6}

Vowels:
{a, e, i, o, u}

iii. Partial Listing Method

This method is used when listing all elements is difficult or impossible. A few elements are listed to show the pattern.

Example:
Natural numbers less than 100:

A = {1, 2, 3, …, 99}

Whole numbers:
W = {0, 1, 2, 3, …}

iv. Set Builder Method

The set-builder method describes a set by a property or condition that its members must satisfy.

A representative element and its condition are written inside braces.

Example:
A = {1, 2, 3, …, 10}

Set-builder form:
A = {x : x ∈ N and x < 11}

📝 Questions on Description of Sets

A. 5 ∉ A, 8 ∈ A, 0 ∈ A
B. 5 ∈ A, 8 ∈ A, 0 ∉ A
C. 5 ∈ A, 8 ∉ A, 0 ∉ A
D. 5 ∉ A, 8 ∉ A, 0 ∈ A

Answer: C

2. M = {2, 3, 5, 7, 11, 13}. Which statement best describes M?

A. Even numbers less than 15
B. Odd numbers less than 15
C. Prime numbers less than 15
D. Multiples of 3

Answer: C

3. E = {1, 3, 5, …, 99}. What is E?

A. Odd natural numbers up to 99
B. Even natural numbers up to 99
C. Prime numbers up to 99
D. Multiples of 3 up to 99

Answer: A

4. D = {1, 3, 5, …}. Which is the correct set-builder form?

Answer: C — D = {x ∈ N : x = 2n − 1, n ∈ N}

1.2 The Notion of Sets

1. Empty Set

A set that does not contain any element is called an empty set, void set, or null set.

It is denoted by: ∅ or { }

If A = {x : 1 < x < 2, x is a natural number}, then A is an empty set because there is no natural number between 1 and 2.

2. Finite and Infinite Sets

A set containing a definite number of elements is called a finite set.

A set which is not finite is called an infinite set.

Examples:
• Days in a week → Finite
• African countries → Finite
• Whole numbers → Infinite
• Real numbers → Infinite

3. Equivalent Sets

Two sets are equivalent if there is a one-to-one correspondence between their elements.

For finite sets:
n(A) = n(B)
A = {1, 2, 3, 4}
B = {Red, Blue, Green, Black}

Both contain four elements, so A and B are equivalent.

4. Equal Sets

Two sets are equal if they contain exactly the same elements. The order does not matter.

A = {1, 2, 3, 4}
B = {4, 3, 2, 1}

Therefore: A = B

5. Subsets

A set A is a subset of B if every element of A is also an element of B.

A ⊆ B

If A is not a subset of B:

A ⊈ B

If A = {1, 2, 3}, then:

{1, 2} ⊆ A
If a set A has n elements, the number of subsets is:

2ⁿ

6. Proper Subset

A is a proper subset of B if every element of A is in B, but A is not equal to B.

A ⊂ B

A = {2, 5, 7}
B = {2, 5, 7, 8}

Therefore: A ⊂ B
Number of proper subsets = 2ⁿ − 1

7. Power Set

The power set of A is the set of all possible subsets of A, including the empty set and A itself.

P(A)

Let A = {1, 2}

P(A) = {∅, {1}, {2}, {1,2}}

Number of subsets = 2² = 4

1.3 Operations on Sets

Universal Set

A universal set U contains all elements under consideration.

Union of Sets

The union of A and B contains all elements that are in A, in B, or in both.

A ∪ B = {x : x ∈ A or x ∈ B}

Intersection of Sets

The intersection contains elements that belong to both A and B.

A ∩ B = {x : x ∈ A and x ∈ B}

A = {0, 1, 3, 5, 7}
B = {1, 2, 3, 4, 6, 7}

A ∪ B = {0, 1, 2, 3, 4, 5, 6, 7}

A ∩ B = {1, 3, 7}

Difference of Sets

A − B contains elements that are in A but not in B.

A − B = {x : x ∈ A and x ∉ B}

Complement of a Set

The complement of A contains all elements in U that are not in A.

A′ = {x : x ∈ U and x ∉ A}

Important Laws

(A′)′ = A

A′ = U − A

A − B = A ∩ B′

(A ∪ B)′ = A′ ∩ B′

(A ∩ B)′ = A′ ∪ B′

⭕ Venn Diagrams

A Venn diagram is a pictorial representation of sets. Sets are usually represented using circles inside a rectangle representing the universal set.

Venn diagrams help us understand union, intersection, difference and complement visually.

Symmetric Difference

The symmetric difference between A and B contains elements belonging to A or B, but not both.

A Δ B = (A − B) ∪ (B − A)

A = {1, 2, 4, 5, 8}
B = {2, 3, 5, 7}

A − B = {1, 4, 8}
B − A = {3, 7}

Therefore:
A Δ B = {1, 3, 4, 7, 8}

Cartesian Product of Two Sets

The Cartesian product A × B is the set of all ordered pairs (a,b) such that a ∈ A and b ∈ B.

A × B = {(a,b) : a ∈ A and b ∈ B}

Let:
A = {2, 4, 6}
B = {1, 3}

A × B = { (2,1), (2,3), (4,1), (4,3), (6,1), (6,3) }

1.4 Application of Sets

Sets are used to represent and solve problems involving groups of objects or people with common or overlapping characteristics.

They are useful in:

  • Surveys
  • Classification of data
  • Probability
  • Comparing groups
  • Finding relationships between groups
n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
Given:
n(A) = 20
n(B) = 28
n(A ∪ B) = 36

Find n(A ∩ B).

36 = 20 + 28 − n(A ∩ B)

n(A ∩ B) = 48 − 36

n(A ∩ B) = 12
